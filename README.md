# 🎧 音频自动闪避助手 (Audio Duck)

一个 Windows 小工具：在**直播**、**语音聊天**等场景下，自动压低背景声音，让人声更突出。

- 直播 / 录制时：检测到麦克风说话 → 自动压低桌面输出音量（凸显人声）
- 语音聊天时：语音应用（如 oopz、QQ、微信、YY）一有输出 → 自动压低音乐播放器（如网易云音乐、QQ 音乐）的音量

自带美观的暗色主题窗口，实时电平表、状态提示与运行日志，设置自动保存。

---

## ✨ 功能一：直播人声突显（麦克风闪避）

**适用场景**：直播、游戏解说、录音。此时电脑输出设备同时承载桌面音频与麦克风人声（由 OBS 等推流软件混合，或声卡"立体声混音"输出）。

- 持续监测麦克风输入电平
- 检测到说话（电平超过阈值）→ 平滑压低桌面主音量
- 停止说话并经过释放延迟 → 平滑恢复原音量

> 🎨 **界面**：淡粉半透明玻璃质感窗口，背景图从 `114514` 文件夹中随机挑选（每次打开不同），窗口尺寸自动适配所选图片比例（完整显示不裁剪）。

## 💬 功能二：语音聊天闪避（音乐闪避）

**适用场景**：一边用 oopz / QQ / 微信语音，一边用网易云音乐 / QQ 音乐听歌。

- 持续监测语音聊天应用的输出电平
- 语音应用一有声音输出 → 平滑压低音乐播放应用的**会话音量**（不影响其他应用）
- 语音静默并经过释放延迟 → 平滑恢复音乐音量

## 📦 环境要求

- Windows 10 / 11（x64）
- Python 3.9+（[python.org](https://www.python.org/downloads/) 下载，安装时勾选 **Add python.exe to PATH**）
- 联网（首次运行需安装依赖）

## 🚀 安装与运行

**方式一（推荐，静默无黑窗口）**：双击 `AudioDuck.vbs`

直接无控制台启动图形界面（首次也会自动补装依赖）。任务栏与标题栏显示的是应用专属图标（麦克风），不再是 Python 图标。

**方式二（可视化启动/排查）**：双击 `run.bat`

会显示命令行窗口输出安装/启动过程，便于首次安装和排查问题；启动的图形界面同样无 Python 控制台。

**方式三（桌面快捷方式）**：桌面上的「音频自动闪避助手」快捷方式

直接双击即可运行，无任何控制台；桌面与任务栏均显示麦克风专属图标。
若移动了项目文件夹，或需要重新创建，双击项目内的 `create_shortcut.bat` 即可。

（交付包内已附带预装好依赖的 `.venv`；若移动文件夹导致环境失效，`run.bat` 会自动重建。）

## 🎮 使用指南

### 功能一：直播人声突显

1. 点击「麦克风闪避」卡片右上角 **启用**
2. 「麦克风设备」下拉框选择你的麦克风（可点刷新重新枚举）
3. 对着麦克风说话，观察「麦克风电平」条是否变高
4. 调参：
   - **说话触发阈值**：电平超过该值视为"说话"。值越小越灵敏（一般 10~30；背景噪音大就调高）
   - **闪避后桌面音量**：说话时桌面音量压到原音量的百分之多少（建议 20~40%）
   - **停止说话后恢复延迟**：停止说话后等多久恢复（建议 0.5~1.5 秒，防止句间停顿频繁闪避）

### 功能二：语音聊天闪避

1. 先打开语音聊天软件和音乐播放器，**并让它们开始出声**（音乐在播、麦已开）
2. 点击「语音聊天闪避」卡片右上角 **启用**
3. 在「语音聊天应用」「音乐播放应用」下拉框中选择对应进程
   - 列表来自当前正在发声的应用；也可**手动输入进程名**，如 `oopz.exe`、`CloudMusic.exe`
   - 网易云音乐进程名：`CloudMusic.exe`；QQ 音乐：`QQMusic.exe`；QQ：`QQ.exe`；微信：`WeChat.exe`
4. 让语音软件说几句话，观察「语音输出电平」条与音乐音量变化
5. 调参：触发阈值、闪避后音乐音量、静默恢复延迟（含义同上）

> 💡 两个下拉框都能手动输入：只要知道进程名，即使应用没在发声也能提前填好。

## 🔄 自动更新

程序启动时会自动检查更新源；状态栏也有「检查更新」按钮可手动检查。发现新版本后弹窗询问，确认后自动下载并替换自身（程序短暂关闭后自动重启为最新版）。

### 搭建更新源（只需一次）

1. 把新版 exe 和一个 `version.json` 放到一个可访问的 HTTPS 地址（推荐 GitHub / Gitee Releases，或任意静态文件托管）：

   `version.json` 内容：
   ```json
   {
     "version": "1.1.0",
     "url": "https://你的地址/AudioDuck.exe",
     "sha256": "可选，新版 exe 的 SHA-256",
     "notes": "本次更新内容说明"
   }
   ```

2. 修改 `updater.py` 顶部的 `UPDATE_URL` 为你的 version.json 地址，然后重新打包：
   ```python
   UPDATE_URL = "https://你的地址/version.json"
   ```

> 也可不改代码：在程序的配置文件 `%APPDATA%\AudioDuck\config.json` 里加 `"update_url": "https://你的地址/version.json"`，程序会优先使用它。

- 版本号比较：数字逐段比较（`1.10.0` > `1.9.9`），版本号只增不减即可触发更新
- `sha256` 可选：提供则下载后校验，防止文件损坏/被篡改
- 更新源务必使用 HTTPS，避免中间人篡改下载的 exe

## 🔧 常见问题

**Q1：下拉框里没有我的麦克风？**
点「刷新」。若仍没有，可能是驱动问题，可尝试在系统"声音设置 → 输入"中确认设备可用。

**Q2：下拉框里没有我的音乐 / 语音软件？**
音频会话只在应用**正在发声**时出现。先让音乐播放、语音软件开麦，再点「刷新」。也可以直接手动输入进程名（任务管理器 → 详细信息 可查看）。

**Q3：说话时音量没有变化？**
- 确认右上角开关已启用、麦克风电平条在说话时明显升高
- 阈值调低一些（更灵敏）
- 查看日志是否有报错（如"无法打开麦克风"）

**Q4：音量会恢复吗？**
会。停止说话 / 语音静默后按延迟时间平滑恢复；直接关闭本程序也会自动恢复。

**Q5：关掉软件后音量没恢复？**
极少数情况下（程序被强制结束、崩溃），音量可能停留在闪避状态，手动调一下音量即可。

**Q6：会占用很多资源吗？**
不会，核心逻辑 50ms 轮询一次电平，CPU 占用可忽略。

**Q7：为什么闪避的是主音量而不是某个应用？**
直播场景下推流软件捕获的是整条输出总线，压低主音量即可降低推流中的背景声（麦克风由推流软件单独采集，不受影响）。

**Q8：双击后窗口一闪而过 / 打不开？**
若启动时发生错误，程序会弹窗提示并把详细原因写入程序目录下的 `error.log`，打开它即可看到具体报错；也可以直接在命令行运行 `python main.py` 查看完整输出。

## 🧩 技术原理

- 基于 Windows **WASAPI**：`pycaw` 枚举/控制各应用的音频会话（`ISimpleAudioVolume`、`IAudioMeterInformation`）
- `sounddevice` 采集麦克风电平（RMS）
- 平滑渐变（约 0.5 秒起落）避免音量突变，带迟滞与释放延迟防抖
